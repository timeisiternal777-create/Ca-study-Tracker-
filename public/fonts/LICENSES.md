# Font licences

The font files in this folder are open-licensed typefaces, self-hosted so the app works offline. The `.woff` files are trimmed copies used on screen. The `.ttf` files are embedded whole into the PDF reports.

The two Voyage fonts reserve their original names, so the trimmed copies are renamed inside the file ("Voyage Title", "Voyage Story"). The copyright lines are kept.

Licence texts:

* SIL Open Font License 1.1: https://openfontlicense.org
* GUST Font License: https://www.gust.org.pl/projects/e-foundry/licenses

Both licences allow use, bundling and redistribution. The OFL asks that the licence text travels with the fonts when you redistribute them. The full text for Comic Relief is included as `OFL-ComicRelief.txt`. If you publish this project, add the full licence files for the other fonts next to this one.
